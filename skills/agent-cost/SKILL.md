# agent-cost

`<skill_dir>` is the folder that holds this `SKILL.md` (`${CLAUDE_SKILL_DIR}`). `$AC` is `<skill_dir>/bin/agent-cost`
as an absolute path; it needs `python3` ≥ 3.10. Always type `$AC` the same way so permission rules match.

## Core rule

**The main agent never prints cost data as text.** The report page is generated by code and served by a local server;
the main agent runs one command and relays only the URL. No sub-agent is needed.

## Operations

| Request | What you do |
|---|---|
| no args, `serve`, `list`, a SID | Run the live page (below). With a SID, pass `--session <SID>` instead of the main session id. |
| `report` | Static export: run `$AC report --session <MAIN SID>`; it writes an HTML file, opens it and prints its absolute path as the last line. Relay that path on its own line, full absolute path. |
| `stop` | Run `$AC serve --stop` and say what it printed. |
| `show [SID]`, `list --json` | For agents and debugging: run `$AC show [SID\|--latest] --json` or `$AC list --json` and use the output yourself; do not paste it to the user. Every session, built-in agent and the root totals carry `time: {wall_s, active_s, waiting_s, idle_s}` (`null` when unknown); waiting is time spent waiting on the session's own sub-agents. |
| `export` | For other plugins: `$AC export --session <SID> [--since ISO] [--until ISO] --json` prints the session's own cost, tokens and wall/active/waiting/idle time and every descendant's (contract 1, read-only; unknown session exits 1). `$AC version --json` prints the contract number. |
| `scan [--since 30d]` | Run `$AC scan`: backfills sessions from the transcript history. Say what it printed in one line. |
| `doctor` | Run `$AC doctor` and show the output. |
| `setup` | Run `$AC setup`: it prints the diff for `~/.claude/statusline/dashboard.js`. Show it. |
| `setup --apply` | Modifies the user's `~/.claude/statusline/dashboard.js`. Run it **only after the user explicitly approves the diff in this conversation**. |

## Live page (default)

1. Get this session's id: `${CLAUDE_SESSION_ID}` if substituted, else `echo $CLAUDE_CODE_SESSION_ID`.
2. Run, in one Bash call: `<skill_dir>/bin/agent-cost serve --session <MAIN SID>`.
   It starts the local server in the background (or reuses the running one), opens the page in the browser and prints
   a one-line summary and then the URL alone on the last line, e.g. `http://127.0.0.1:47821/#<sid>`.
3. Reply with only that URL on its own line.

The page updates by itself while it is open: the server rescans recent transcripts every ~10 s and the page re-renders
when the data changes. The server listens on 127.0.0.1 only (unless `--host`/`AGENT_COST_HOST` is set) and stops after 2 h without requests.

### Reaching the page from another device (e.g. phone over Tailscale)

`serve --host <addr>` (env `AGENT_COST_HOST`) sets the bind address; `--allow-host <name>` (repeatable or
comma-separated, env `AGENT_COST_ALLOWED_HOSTS`) adds accepted Host header names. Flags win over env vars. The page has
no auth, so a non-loopback bind prints a warning; other Host headers still get 403. Example:
`AGENT_COST_HOST=0.0.0.0 AGENT_COST_ALLOWED_HOSTS=<tailnet-ip>,<machine>.<tailnet>.ts.net <skill_dir>/bin/agent-cost serve --no-open`,
then open `http://<tailnet-ip>:47821/`. A running server with different settings is restarted.

## Status line segment

`session <start> · <duration> · act <active> wait <waiting> idle <idle> · Σ $total · agents $X (n)`. Active is the root
session's working time (gaps between transcript records, minus waits for the user and any gap over 300 s), waiting is
the rest of that time during which one of its sub-agents was running (shown only when non-zero), idle is what remains of
the duration; updated when a turn stops. The total sums the whole agent tree (the session, built-in
sub-agents and Herdr children recursively). A sub-agent session shows `[sub:<role> d<depth>]` next to the profile label and the session line shows
`self $X` instead of `agents`.

## Where data lives

- State dir: `$AGENT_COST_STATE_DIR`, else `${XDG_STATE_HOME:-~/.local/state}/agent-cost/`.
- `roots/<root_session_id>.json`: one file per main session with the whole tree (schema in the README).
- `sessions/<root>/` per-session records, `cache/` transcript aggregates, `reports/` generated HTML.
- `server.json` (pid, port, version of the running server) and `server.log`.
- Config: `~/.config/agent-cost/config.json`: `project_roots` (folders the report groups sessions by) and
  `visible_roots` (default `["~/Desktop"]`): roots whose cwd is outside are hidden from `list` (`--all` shows them) and
  the sidebar ("Show hidden (N)") and left out of period totals.
- Auxiliary sessions (verify-loop triage/reviewer/QA/retro, vault agents, sessions in `~/.claude` or a scratchpad) are
  linked to their main session from Herdr launch records, vloop state (`~/.local/state/agent-verify-loop`), prompts and
  scratchpad paths, and carry a `purpose` (`verify:*`, `vault`, `harness`, `task`).
